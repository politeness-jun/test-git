
# 图书管理系统 使用说明

## 1. 系统介绍

本系统使用C语言开发，控制台字符界面，分为**管理员**与**读者**两种角色。
实现图书管理、图书分类、用户管理、图书借阅/归还/续借、逾期罚款、公告发布等功能。

> ⚠️ 重要提示：所有数据保存在内存中，**关闭程序后新增的数据会全部丢失**，不会持久保存到文件。

编译命令：

```bash
gcc test.c -o test.exe
./test.exe
```

## 2. 初始登录账号

| 角色 | 账号 | 密码 |
| :--- | :--- | :--- |
| 管理员 | admin | admin123 |
| 读者 | reader | 123456 |

> 账号为字符串，不是数字ID！登录界面账号输入 `0` 可直接退出系统。

## 3. 管理员功能（登录 admin）

```text
=====管理员菜单=====
1图书列表 2新增图书 3删除图书
4分类管理 5用户管理 6发布公告
7查看公告 8数据统计 9返回登录页 0退出程序
```

1. **1 图书列表**：展示所有图书ID、书名、作者、库存、可借数量。
2. **2 新增图书**：依次输入书名、作者、出版社、简介、库存数量、分类ID。图书数量达到上限时无法新增。
3. **3 删除图书**：输入图书ID进行删除。**存在未归还借阅记录的图书禁止删除**。
4. **4 分类管理（子菜单）**
    - 1 查看分类：查看全部图书分类列表
    - 2 新增分类：创建新的图书分类
    - 0 返回：返回管理员主菜单
5. **5 用户管理（子菜单）**
    - 1 查看全部：查看所有用户ID、账号、姓名、账号状态
    - 2 新增用户：新建管理员/读者账号，账号不可重复
    - 3 启用/禁用：输入用户ID，锁定或解锁账号；被禁用账号无法登录
    - 0 返回：返回管理员主菜单
6. **6 发布公告**：输入公告标题与内容，发布系统公告。
7. **7 查看公告**：浏览全部已发布公告。
8. **8 数据统计**：查看图书总数、借阅记录数量、当前借出图书数量、用户总数。
9. **9 返回登录页**：退出管理员菜单，回到登录界面。
10. **0 退出程序**：直接关闭整个系统。

## 4. 读者功能（登录 reader）

```text
=====读者菜单=====
1图书列表 2搜索图书 3借阅图书
4归还图书 5续借图书 6我的借阅记录
7缴纳罚款 8查看公告 9返回登录页 0退出程序
```

1. **1 图书列表**：查看全部图书信息。
2. **2 搜索图书**：输入书名或者作者关键词模糊检索图书。
3. **3 借阅图书**：查看图书列表，输入图书ID借阅。单人最多可借5本书，达到上限不能继续借阅；无库存图书不可借阅。
4. **4 归还图书**：输入借阅记录ID归还图书。系统自动计算逾期罚款。
5. **5 续借图书**：输入借阅记录ID续借，重置借阅到期时间，清空当前逾期罚款。仅支持**未归还**的借阅记录。
6. **6 我的借阅记录**：查看本人全部借阅，显示书名、借阅日期、状态、罚款金额与缴费状态。
7. **7 缴纳罚款**：输入借阅记录ID，结清该条记录的逾期罚款。仅可对已归还、未缴费的记录缴费。
8. **8 查看公告**：查看管理员发布的公告。
9. **9 返回登录页**：退出读者菜单，回到登录界面。
10. **0 退出程序**：直接关闭整个系统。

## 5. 业务规则

1. 借阅期限：30天，超出后按**1元/天**计算逾期罚款。
2. 单人最大借阅数量：5本。
3. 图书有未归还借阅记录时，管理员不能删除这本图书。
4. 被禁用的用户账号无法登录系统。
5. 续借成功后，借阅时间重新从续借当天开始计算。
6. 归还图书后才可以缴纳对应的逾期罚款。

## 6. 常见问题

1. 登录提示账号密码错误：核对账号（`admin` / `reader`），注意账号是英文字符串，不是数字。
2. 无法删除图书：这本书还有读者未归还，需要等归还后再删除。
3. 借阅失败：达到个人借书上限，或者图书可借库存为0。
4. 续借失败：借阅记录不存在、图书已经归还，记录无效。
5. 缴纳罚款失败：记录未归还或者罚款已经缴清。
